# Code of Conduct

## Our Pledge

This project is committed to providing a welcoming, friendly, and respectful
environment for everyone who participates — contributors, maintainers, and users
alike — regardless of background or identity.

## Our Standard

We adopt the [Contributor Covenant][covenant], version 2.1, as our code of
conduct. Please read it for the full set of expectations and guidelines:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be kind, assume good faith, give and accept constructive feedback
gracefully, and help keep this a community where people feel safe to participate.

## Scope

This Code of Conduct applies within all project spaces — the issue tracker,
pull requests, discussions, and any other official channel — and when an
individual is representing the project in public spaces.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to
the maintainer at **takeo.obara@attm.co.jp**. All reports will be reviewed and
investigated promptly and fairly, and the reporter's privacy will be respected.

For the full enforcement guidelines, see the Contributor Covenant linked above.

[covenant]: https://www.contributor-covenant.org/
